# v30.0.0 发布说明

这次的重点不在"多了几个按钮"，而是三件以前没有的地基：界面规范、双态联机、多语种，外加一条不用重下完整包的更新通道。

## 界面规范

组件层整体对齐 WulonSpec：

- 字体换成 Sora VF / MiSans VF / Geist Mono VF 三件可变字体，中文不再靠系统黑体兜底
- MiSans 做 GB2312 子集，从 11.9MB 压到 2.6MB，桌面版与网页版共用同一份
- 动效抽成 token（曲线、时长、按压比例），按钮、输入框、开关、对话框统一走同一套
- 分段控件补上滑动指示块，按真实宽度测量，选项长短不一时也对得齐
- 新增进度条、骨架屏、面包屑，表格与工具提示统一到一套规格

## 联机：临时房间 / 常驻服务器

「朋友能不能进来」卡片里加了双态切换：

- 临时房间：玩完就关，发邀请即可，不要求固定地址
- 常驻服务器：长期开放，先检测，再把验证过的地址固定发给朋友

选择写进实例的 `lifecycle` 字段，改变的是卡片说明、给朋友的提示和建议动作，服务器本身只有一套。

## 多语种（简体中文 + English）

- 界面文案、引导与诊断文案全部接入 i18n，默认中文，可在设置里切换英文
- 中文原文作为调用处的 fallback：英文缺条目时回退中文，不会出现空白或 key
- 非组件代码（同步引擎、诊断结论、可达性判定）通过 `tGlobal` 取词，与组件同源
- 一致性由 `scripts/check-i18n.cjs` 守着，检查缺失、空值、重复 key

英语界面下保持中文的内容是有意为之：服务器名、Mod 名、版本号、文件路径、日志与命令属于数据，不是界面文案。

## 轻量更新

桌面版日常更新不再需要重下 273MB：

| | 完整包 | 轻量更新 |
|---|---|---|
| 体积 | 273MB | 4.37MB |

流程：读 `update.json` → 下载 `app.asar.gz` → 校验 sha256 与大小 → 退出后由独立进程替换 `app.asar` → 失败自动用 `.bak` 还原 → 重启。

`update.json` 带当前 Electron 运行时版本，运行时变了才提示下载完整包，避免新主程序跑在旧运行时上。设置页「关于」区块里有检查更新入口；网页版刷新即为最新，不需要这条通道。

## 工程

- 版本号统一到 `30.0.0`
- 新增脚本：`scripts/make-update.cjs`（生成更新包）、`scripts/update-e2e.cjs`（更新链路自检）、`scripts/check-i18n.cjs`（词典一致性）、`scripts/subset-misans.py`（字体子集化）

## 已知边界

- 网页版仍需本机助手才能执行文件和服务器操作；「轻」体现在不用装 273MB 桌面版，而不是完全免安装
- 内容数据（Mod 中文名、百科条目）未翻译，英文界面下这些数据保留原文
- 轻量更新只覆盖应用层；Electron 运行时升级需要完整包
