# AI 排错 · 怎么用

## 给用户

出问题的时候，界面上的**崩溃诊断卡**右上角有一个「让 AI 看看」，点一下会把一段提示词复制到剪贴板：

```
我是 Wulon's MCSS 的用户……（附带实例信息、症状、最近日志、知识库路径）
```

把它粘给任何一个能读文件的 AI（本机的 CLI agent、IDE 里的助手、网页版都行）。
如果 AI 读不到本机文件，把这段话连同 `docs/ai/knowledge.md` 的内容一起贴过去。

## 给 AI

1. 先读 `docs/ai/knowledge.md`（症状 → 原因 → 修法）；
2. 用户会给你一段包含「实例信息 + 症状 + 最近日志」的文本；
3. 按知识库里的**排错纪律**回答：先结论、再最多 3 步、动作可逆；
4. 需要更多证据时，明确告诉用户去界面哪里复制（控制台可导出 `.log`）。

## 为什么不做成“自动修复”

自动改配置/删文件的风险太高。当前的边界是：
- 机器能确定的（预检、崩溃模式）→ 程序自己判断 + 一键修复；
- 判断不了的 → 把现场打包给 AI，由人确认后执行。

这也是 PCL「炒饭」的思路：**把已知的坑写成路径，把未知的交给更会推理的一方。**
