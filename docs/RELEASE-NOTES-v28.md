# v28.0.0 发布说明

> 2026-10-31 · 一个“把 v27 收干净”的大版本，不堆新功能，补发布、维护、翻译三件事。

## 主要变化

- **文案整体升级**：按《文案优化稿》回填 522 处，用户可见片段按上下文合并；技术性提示保留原样。
- **关于页**：去掉“特别感谢”与数据来源署名；作者头像改为隐刻INCO 圆形头像；作者/项目主页按钮按配置显示。
- **i18n 框架**：`I18nProvider` / `useI18n` / 词典回退 / `mcss.locale` 持久化已就绪；页面迁移与语言入口下一轮。
- **多世界版本门禁**：1.16.2 以下提示原版不支持；1.16.2–26.0 提示当前生成器只支持 26.1 格式；未知版本禁用生成，避免写出起不来的数据包。
- **联机页可执行化**：体检后直接给「下一步」；有公网 IPv6 时生成 `[v6]:25565` 并一键复制，地址行也可单独复制；总览「联机状态」改名为「朋友能不能进来」。
- **零基础路径**：网络页主路径只保留「能不能进 + 下一步 + 复制地址」，NAT/IPv6/UPnP 等技术细节折叠到「技术详情」；不再假设校园网、公网 IP 或网络知识。
- **主链路可执行化**：新建服务器有「不知道怎么选？」与推荐配置；预检检查中不再甩技术清单；邀请对话框可直接复制地址，没地址时给「去开中转线路」出口。
- **世界/备份**：顶部先说明「导出完整存档」和「时间机回滚」的区别，避免用户在两个备份入口之间猜。
- **客户端与设置**：客户端空目录给「选择 .minecraft 目录」，不再在界面里提 PCL/HMCL；网页版设置卡不再固定显示「本机助手已连接」。
- **错误态说人话**：AI 回复没有配置、服务端缺启动文件、诊断码损坏、配置项不存在时，都改成用户能处理的中文句子。
- **诊断码给下一步**：解析后按「连不上 / 缺模组 / 缺版本 / 客户端正常」给出可执行建议，连不上时可直接去联机页；首次启动就绪后的主按钮改成「去启动服务器」。
- **弹窗说人话**：AI 配置助手补三步用法与安全字段说明；导入服务器把「核心类型」改成「服务端类型」；客户端页与诊断文案去掉插件服/隧道等术语。
- **配置 / 内容页**：顶部说明这里改什么、默认值能不能留、保存后是否要重启；内容页说明安装/禁用行为。
- **单人存档导入**：用现有客户端开服时，可把 `.minecraft/saves` 里选中的存档复制成服务端 `world`；原存档保留，自动清掉 `session.lock`，目标已有 world 时拒绝覆盖。
- **项目清查**：v28 审计、链接/占位清单、CI、部署清单。
- **发布链路**：GitHub Actions（typecheck / vitest / node:test / Rust / parity / 桌面构建 / 网页构建 / release check）；`release:agent` 产出 v28 助手 zip 与 SHA256。
