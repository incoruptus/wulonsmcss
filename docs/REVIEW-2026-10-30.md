# 2026-10-30 · 对抗性 + 人体工学审查

> 范围：v27.3.0 的桌面壳、网页 agent、React UI、开服/进服主链路。
> 方法：四条线并行——在线调研（Minecraft 版本/核心/竞品）、IPC 安全审计、新手 UX 走查、功能盘点；关键结论都用代码/真机/测试复核。
> 结论：**主干是闭合的**（建服→预检→启动→控制台→装内容→备份→邀请→进服），但“新手第一公里”和“网页版边界”存在真实断点。本轮修了 P0 与多数 P1，剩余项在 §5。

## 1. 在线调研（事实，带来源）

- 版本编号：2026 起 `YY.D.H`；**26.1 起最低 Java 25**（不是 21）。1.21.11 是旧编号最后一版（Java 21）。26.1/26.1.1/26.1.2 协议同为 775，26.2=776、26.3=777，跨协议不能互连。
  - https://minecraft.wiki/w/Java_Edition_26.1
  - https://minecraft.wiki/w/Version_formats
- 核心：Vanilla 不能装插件/模组；Paper/Purpur 能装插件、玩家用原版客户端；Fabric/Forge/NeoForge 是模组平台，**玩家也要装**；26.x 的 NeoForge 生态明显比 1.21.1 薄。
  - https://papermc.io/ · https://purpurmc.org/ · https://fabricmc.net/use/server/
- Paper/Purpur 的 26.1 组只有 26.1.1/26.1.2，没有 “26.1”；应自动落到 26.1.2。
  - https://fill.papermc.io/v3/projects/paper
- 开服常识：EULA 必须显式同意；端口默认 25565；1.20.5+ 要 Java 21、1.18+ 要 17、更老要 8；`online-mode=true` 默认只允许正版。
  - https://minecraft.wiki/w/Tutorial:Setting_up_a_Java_Edition_server
  - https://minecraft.wiki/w/Server.properties
- 生态数量（Modrinth search，2026-10-30 实测，`project_type` + `versions` 过滤）：Mod 26.3=9,326 / 26.1.2=15,497 / 1.21.11=19,922 / 1.21.1=32,547；插件 26.3=3,049 / 26.1.2=6,760 / 1.21.11=12,599 / 1.21.1=14,523。
- 竞品：PCL2 先给“最新/正式/预览”分类再选加载器；HMCL 直接列“该版本支持的加载器”并提示 Fabric API；Aternos 对弃用版本打红标、禁止新装。结论：**先意图、后版本、再技术细节**，不要一上来给六家核心下拉。

## 2. P0（已修）

### P0-1 `?agent=` 任意主机 + agent CORS `*` → 配对令牌外泄 → 任意命令执行

原链路：网页版 `agentBaseUrl()` 把 URL 里的 `?agent=http://attacker.tld` 原样存进 localStorage；`httpClient` 每个请求带 `x-mcss-token`；agent 的 CORS 是 `*`。攻击者拿到 token 后可 `fs:read/fs:write/proc:run`。

修复：
- `agentBaseUrl()` 只接受 **loopback**（`127.0.0.1` / `localhost` / `::1`），非本机地址不保存、不使用，并清掉历史坏值。
- `createHttpClient` 再做一次纵深防御：非 loopback 不附带 token，SSE 也不把 token 拼进 query。
- 相关：`app:open-external` 只允许 http/https；agent `open_external` 同样；`open_path` 改用 explorer 参数，避免 `cmd /c start` 的 `&` 注入。
- 仍未做：agent CORS 仍反射为 `*`（token 已不会外泄，但建议下一轮收紧 Origin）；token 轮换未做。

## 4. 人体工学：新手第一公里

### 4.1 走查发现（修复前）

- 首启向导第一屏是 **Java 路径列表**，没 Java 就死路，“下一步”灰着不解释；退出还会把 `setupComplete` 永久置真。
- 第二屏一屏 6 个决定：名称、版本（240 条裸下拉）、核心（6 个品牌名）、构建号、安装目录、内存；名称空时按钮灰，**没有任何提示**。
- 核心 hint 用“水桶系/构建号”行话；版本没有“哪个资源多/哪个 Java 能跑”的信息。
- 向导第 3 屏把 Paper/Purpur/Forge 全说成“原版”。
- 配置页直接暴露 `pvp` / `allow-flight` / `peaceful` / `minecraft:normal`。
- EULA 的“修复”一键替用户同意，没有条款链接。
- 停止服务器一键踢人；控制台 /stop 反而有确认。
- 邀请弹窗 5 个等重按钮，默认内网地址，还带“二维码下一步接”。
- 加入页直接启动用固定 `Steve`，却说“你的客户端可以直接进”。
- 桌面默认 `.minecraft` 算成 `%APPDATA%\wulons-mcss\.minecraft`，首次进 `/join` 大概率“没找到”。
- `我的服务器` 永远空（`saveServer` 无调用）；`我的客户端` 保存后 Join 不读。
- 设置里的“日志保留行数 / 界面动画”没有任何消费方。

### 4.2 本轮改法

1. **先问“你想怎么玩”**：原版 / 插件 / 模组三张卡，每张写清“朋友要不要装东西、以后能加什么”。卡下面有“我不知道，用推荐配置”。
2. **版本卡，不是下拉**：26.3（最新）、26.1.2（新版本里最稳）、1.21.11（兼容性最好）、1.21.1（老 Mod 最多）；每张卡带 `Mod 9,326 · 插件 3,049` 和 `Java 25`，数据来自 Modrinth 实时统计（`versions:ecosystem`，30 分钟缓存）。26.1 无 Paper 构建时自动落 26.1.2。
3. **Java 按版本选**：`javaMajorFor` 实现 26→25、1.20.5+→21、1.18+→17；`pickJavaFor` 优先完全匹配，不够就提示“还差 Java 25”并给下载链接，不再把 Java 21 硬塞给 26.x。
4. **名称预填“我的服务器”**，高级项（内存/目录/Java/构建号）折叠；安装按钮禁用时给出原因。
5. **配置页中文化**：新增 `server-properties.ts`，11 个开关、3 个枚举、7 个文本键全部有中文名/后果说明；`online-mode` 明说“关掉后任何人都能进、名字可被冒用”；“源码”改成“原始文件（高级）”；有未保存修改时重新载入要确认。
6. **EULA 变成知情同意**：条款链接 + “我同意并继续”，而不是“修复”；EULA 缺失从 warn 改为 error，预检会拦住。
7. **停服统一确认**：首页/实例头/控制台都走同一个 `StopServerDialog`，显示在线人数和后果。
8. **加入页说人话**：直接启动标“（离线）”，提供游戏内名字输入，明确“只对关闭正版验证的服有效”；默认 `.minecraft` 用 `info.minecraftDir`；打开房间自动存进“我的服务器”，同地址去重；`Client` 保存的目录 Join 会优先用。
9. **邀请减负**：主按钮“复制发给朋友的邀请”，网页链接只在有部署地址时出现；没有地址就发房间码/进服包，不再伪造 404；删掉二维码占位。
10. **网页边界**：定时任务、停服自动备份、樱花穿透在网页版明确标注/隐藏；Join 在窄屏隐藏侧栏，手机打开邀请链接不再被 228px 侧栏挤扁。
11. **设置真生效**：`maxLogLines` 写入 server store；`animationsEnabled` 落到 `<html class="no-anim">`。

## 5. 仍未解决 / 下一轮建议

1. **NeoForge**：本机 maven DNS 污染，真实安装未验证；`neoforgeBuilds` 失败仍返回 `[]`（UI 会显示“没有构建”而不是“连不上”）。建议改成结构化错误并加“换 Fabric/1.21.1”引导。
2. **agent CORS / token 轮换**：P0 链已断，但 CORS 仍是 `*`；建议 Origin allowlist + token 轮换。
3. **frpc 已存在 exe 的校验**：下载时有 digest，复用缓存时没有；建议保存 `.sha256` 并复核。
4. **备份并发/GC**：同秒撞名已加毫秒+序号；但没有并发锁；快照对象/`world.before-restore-*` 只增不删。
5. **服务器 jar 完整性**：`installServer` 仍可能因缓存/源问题拿到旧 jar；无 size/hash 的统一约束。
6. **`server:memory` 网页版恒 0**；**定时任务只调度一个 active 实例**；**`quickActions`/`accent`/`consoleViewMode`/`detectedJava`/`autoSync` 是死字段**。
7. **两套仪表盘**（`Overview` 与 `InstanceOverview`）信息重叠，建议合并。
8. **`roomWebLink` 默认 origin 仍是占位域名**；部署后应把 `VITE_PUBLIC_URL` 配好。
9. **移动端只处理了 Join**；其他页面在手机上仍是 228px 侧栏。
10. **对比度**：浅色主题的 `gray-700/800` 12px 文本未达 WCAG AA（需单独调色板，避免影响边框）。
11. **文档旧数字**：PROJECT/ROADMAP/agent README 仍有过期状态；FEATURE-MAP 已给对照。
