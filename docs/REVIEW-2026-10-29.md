## 一、阻断级（会丢数据 / 主线失效 / 上线当天必炸）—— 已全部修复

### 1.1 快照恢复可被 manifest 带出存档目录，且谎报成功

- 证据（探针）：manifest 写 `../escaped2.txt` 时
  `restoreSnapshot → ok:true, restored:1`，
  文件写进服务器根目录、**`world` 根本没被创建**，原存档已被挪成 `world.before-restore-*`。
- 为什么是阻断级：用户看到"恢复成功"，实际存档没了。
- 修复：动手前整份校验（`..`、绝对路径、盘符、空路径全拒），空快照拒绝，
  恢复后确认 `world` 真的生成；桌面 `electron/ipc/backups.js` 与 agent 同步。
- 测试：`backups.test.js` 4 条对抗用例（穿越、绝对路径/盘符/空、空快照与非法名、整包名穿越）。

### 1.2 「直接进游戏」对 PCL2 装的版本永远匹配不上

- 证据：真机 `.minecraft` 有 5 个版本，含 `26.1-Fabric 0.19.3`，
  但 `findMatchingVersion` 返回 null，提示「没找到 26.1 · fabric 的客户端版本」。
- 原因：PCL2 生成**合并版**目录，`id` 就是 `26.1-Fabric 0.19.3`，没有 `inheritsFrom`；
  而代码只认 `inheritsFrom` 或 id 完全相等。PCL2 是国内最常用启动器。
- 修复：`mcVersionOf()` 支持从 id 前缀取版本（`26.1-Fabric 0.19.3` → `26.1`）。
- 真机验证：`versionId=26.1-Fabric 0.19.3`，命令 41 段，**进程存活 20 秒未崩溃**。
- 诚实边界：进程存活 ≠ 已到标题画面，没有截图证明菜单画出来了。

### 1.3 Forge/NeoForge 装好了却起不来（我自己引入的回归）

- 证据：`PreflightDialog` 在 `errors.length > 0` 时 `disabled` 启动按钮；
  而 `checkJar` 只找 `server.jar` / `fabric-server-launch.jar`。
- 后果：新加的 Forge 支持完全不可用。
- 修复：两端预检先看 `libraries/.../win_args.txt`；`preflight.test.js` 5 条。

### 1.4 网页版「下载助手」按钮指向 `https://github.com/` 首页

- 证据：`WebAgentBanner.tsx` 原代码 `window.open("https://github.com/")`。
- 后果：头号卖点（访问官网→下载助手→即用）断在半路；
  且资源名带版本号，`releases/latest/download/<带版本号>` 每次发版都失效。
- 修复：`lib/links.ts` 集中地址；未配置时**禁用按钮并写明"待配置"**；
  `make-release.cjs` 额外产出稳定名 `mcss-agent-win64.zip`；`RELEASE.md` 补说明。

### 1.5 设置页把「网页版做不到」写死了，而四项其实都能做

- 证据：硬编码 `["新建实例 / 下载服务端", "内网穿透", "多世界数据包生成", "Java 探测"]`。
- 后果：产品在自己的设置页上否定自己的卖点。
- 修复：改成实际能力；徽章「桌面版更全」→「与桌面版一致」；
  「只有桌面版有」只剩窗口按钮与"不用装助手"。
- 佐证：agent 真装了一次 Paper（6 秒、50.4 MB、marker、detect）——不是靠通道计数推的。

## 四、待你拍板（未改）

### 4.1 房间码里带内网 IP

- 现状：`lan` 字段把 `192.168.x.x:port` 明文编进邀请链接；拿到链接的人都能看到。
- 为什么没直接改：内网直连是同 WiFi 场景延迟从 60ms 降到 1ms 量级的关键，
  改默认行为会伤主路径。
- 建议：默认保留，加一个「不带内网地址」的勾选；已先补了文案说明（3.5）。
- 需要你点头的是**要不要那个勾选**。

### 4.2 `fs:remove` 通道的守卫强度

- 已加：空路径 / 盘符根 / 根目录 / 深度 < 2 一律拒绝。
- 仍可能被误用：传入比如 `D:\Games` 这种"合法但危险"的浅路径。要不要再限制"必须在已登记的实例目录之下"？那属于权限模型，属于大改。

## 七、这条审查的局限

1. **没有做真正的威胁建模**：我找的是"会写坏/会谎报/会误导"，不是"恶意本地攻击者"。
   能访问你机器的人，本来就能删你的存档。
2. **没有覆盖全部代码**：`schedule` / `slp` / `mrpack` / `serversdat` 只有既有单测与 e2e，
   没有单独做对抗性用例。
3. **性能没测**：仪表盘轮询、日志缓冲、大世界快照耗时都没有基准数据。
4. **只验证了 Windows**：路径拼接、`win_args.txt`、`tar` 都是 Windows 语义，
   macOS/Linux 从未跑过（产品目前也只承诺 Windows）。
