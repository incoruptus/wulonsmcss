# 中英双语 i18n 框架

> 当前状态（v28 准备）：**只搭框架，不迁页面**。
> 页面仍使用中文原文；`I18nProvider` 已挂到应用根节点，后续可按页面逐步迁移。

## 为什么不用中文当 key

文案还会改。中文一旦变，`{ "旧中文": "English" }` 全部失配，英文等于白做。因此用语义 key：

```ts
t("nav.overview", "总览")
```

第二个参数是当前中文，保证英文词典没跟上时界面不空白；这也让迁移可以按页面分批。

## 文件

| 文件 | 作用 |
|---|---|
| `src/renderer/i18n/core.ts` | Locale、词典、`translate`、插值、回退 |
| `src/renderer/i18n/index.tsx` | `I18nProvider`、`useI18n`、localStorage 持久化 |
| `src/renderer/main.tsx` | 根节点挂 Provider |
| `src/renderer/i18n/core.test.ts` | 回退 / 插值 / 边界测试 |

## 用法

```tsx
import { useI18n } from "@/i18n";

function Example() {
  const { t, locale, setLocale } = useI18n();
  return (
    <div>
      <h1>{t("nav.overview", "总览")}</h1>
      <p>{t("overview.players", "在线 {count} 人", { count: 3 })}</p>
      <button onClick={() => setLocale(locale === "zh-CN" ? "en-US" : "zh-CN")}>切换</button>
    </div>
  );
}
```

- key 用命名空间：`nav.*`、`settings.*`、`overview.*`、`errors.*`。
- 占位符统一 `{name}`；不要用 `${}`（那是模板字符串语法）。
- 英文词典没 key 时回退中文；中文也没有时回退调用处的 fallback。
- 装饰性文案（按钮短标签、错误模板）优先迁；长说明最后迁。

## 加一门语言

1. 在 `core.ts` 的 `LOCALES` 加 `{ id: "ja-JP", label: "日本語" }`，并扩展 `Locale`。
2. 在 `catalogs` 加空词典。
3. 在 `isLocale` 加判断。
4. 设置页的语言选择器读 `LOCALES`，不用改别处。

## 迁移顺序

1. 外壳与导航：`Sidebar` / `MobileNav` / `TitleBar` / `PageHeader`。
2. 设置：外观、语言、关于。
3. 总览：首页与实例概览。
4. 联机 / 邀请 / 加入游戏。
5. 模组 / 世界 / 控制台 / 同步。
6. Electron 与 Rust 的错误文案：单独一层错误码映射，不直接翻中文。

## 验收

- 未翻译页面切到 English 不空白、不报错、不显示 key。
- 已翻译页面切回中文不残留英文。
- 刷新后语言保持；`<html lang>` 跟随。
- 新增 key 不需要改 Provider。
